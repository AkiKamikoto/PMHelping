# PMHelping

Личный инструмент для проектного менеджера, работающего в направлении Bitrix24.
Помогает держать под контролем задачи по проектам, дедлайны, трудозатраты и
напоминания — без необходимости подключения к самому Bitrix24.

## Возможности

- **Дашборд** — сводка по открытым, просроченным задачам и задачам в работе,
  список того, что требует внимания в первую очередь.
- **Клиенты (мини-CRM)** — карточки компаний-клиентов: контактное лицо,
  телефон, email, сайт, мессенджер, ИНН, сфера деятельности, источник,
  адрес и заметки; привязанные проекты и история работы (звонки, встречи,
  письма, заметки) в хронологическом таймлайне.
- **Доска задач** — канбан-доска (К выполнению → В работе → На проверке →
  Готово) с проектами (привязанными к клиенту, с описанием, стадией,
  бюджетом, датами начала и дедлайна), приоритетами, исполнителями и
  дедлайнами задач, перетаскивание карточек между колонками.
- **Учёт времени** — таймер по задаче (старт/стоп) и ручной ввод затраченного
  времени, журнал записей и итоги по задачам.
- **Отчёты** — графики по статусам задач, загрузке исполнителей, затраченному
  времени по проектам и динамике завершения задач за последние 30 дней.
- **Напоминания** — список напоминаний с уведомлениями браузера, можно
  привязать напоминание к дедлайну задачи прямо из карточки.

Все данные хранятся локально в браузере (localStorage). В боковой панели есть
экспорт/импорт данных в JSON — используйте для резервной копии или переноса
на другое устройство.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Стек

React + TypeScript + Vite, Tailwind CSS, Recharts, Zustand (с персистентностью
в localStorage).
